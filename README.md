# langchain-course

The search agent requires a local Ollama model with tool-calling support:

```powershell
ollama pull qwen2.5:1.5b
.\.venv\Scripts\python.exe src\langchain_course\search_agent.py
```

Set `OLLAMA_MODEL` to another Ollama model with tool-calling support if needed.
